I build websites from the first sketch to the live link, and I'm just as comfortable opening up a PC to get it working again.

On the web side I work with HTML, CSS and JavaScript, design in Figma, and build on WordPress when a project calls for it. I've shipped four sites so far and I'm adding React to my stack.
